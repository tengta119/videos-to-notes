挑战一：汉字拼音标注与复杂多音字

中文常用汉字多达数千，生僻字与扩展集更是超过数万。仅仅建立一张“汉字 -> 拼音”的字典表是远远不够的，因为中文存在海量的多音字（Polyphone）： * “重庆”读作 chóng，而“重要”读作 zhòng； * “银行”读作 háng，而“行走”读作 xíng。

计算机必须能够结合上下文分词与词组规则库，才能在句子中判定多音字的真实读音。

挑战二：情感量化与语义深度

情感倾向绝非简单的查字典能够解决。一句表面看似平静的话可能蕴含强烈的讽刺或支持。要量化情感，通常必须从海量标注语料库出发，使用自然语言处理算法或机器学习分类器训练出推理模型。

[!IMPORTANT] 软件工程的“轮子定理”： 软件工程中有一句著名的谚语叫“不要重新发明轮子”（Don't Reinvent the Wheel）。 既然前人已经花费数年时间用汗水打磨出了高可靠性、经过工业级检验的高性能轮子，我们再从头手搓一个不仅费时费力，且搓出来的多半比现成的更为粗糙。 优秀的软件工程师并非所有代码都亲手一行行写，而是深谙如何在开源生态中站在巨人的肩膀上，挑选并组装高质量的轮子。

2. Python 生态枢纽：认识 PyPI 与 pip

(参考时间: 02:40)

既然有现成的轮子，这些由全世界开发者共同贡献的第三方库（Third-party Libraries）存放在哪里？

很多初学者的第一反应是：“在 GitHub 上！”

没错，开源项目的源代码绝大多数托管在 GitHub 上。然而在开发中，如果我们每引用一个库都要把它的 Git 源码 clone 下来、自己配置编译，效率依然极其低下。

  • 在前端领域，我们在 npm 注册表上发布与下载包，只需一行 npm install animejs；
  • 在 Python 领域，对标 npm 的官方公共包仓库名为 PyPI（Python Package Index）。

📷 PyPI 官方公共仓库网站首页概览
在 B 站中打开 (00:03:50)

什么是 PyPI？

PyPI（网址：pypi.org）是全世界所有 Python 共享代码与预编译轮子（Wheel 包）的中心枢纽。截至目前，PyPI 上托管着超过数十万个开源软件包。

当我们在终端敲下：

pip install <包名>

Python 的包管理器 pip 就会跨越网络直连 pypi.org，自动解析版本依赖，将编译打包好的库文件安全、高速地安装至当前 Python 环境的 site-packages 目录中。

6. 交互式神器：深入 Python REPL 模式

(参考时间: 12:40)

库安装好了，我们接下来该怎么跑一跑、验证一下效果？

按照传统思路，很多初学者会新建一个 test.py 脚本，在里面写代码、保存、运行、打印、然后再手动删掉这个临时测试文件。

如果只是想快速试一试几个 API，这种方式显得笨重且拖沓。现代编程语言普遍提供了一种更加优雅迅捷的工具——REPL。

什么是 REPL？

REPL 是 Read-Eval-Print Loop（读取-求值-输出循环） 的首字母缩写： * Read：接收用户在终端键盘键入的表达式； * Eval：Python 引擎就地对代码进行求值计算； * Print：无需显式写 print()，直接把计算出的结果在屏幕上回显； * Loop：等待用户下一次输入，周而复始。

在激活了虚拟环境的终端中，直接敲入 python 回车，终端提示符就会转变为经典的 >>>：

📷 进入 Python 交互式 REPL 模式与三箭头提示符
在 B 站中打开 (00:13:15)

在 REPL 中，任何表达式都会即时得出结果：

>>> 1 + 1
2
>>> x = 10 + 20
>>> x
30

跨语言的 REPL 思想

不仅 Python 拥有 REPL，几乎所有现代化语言都具备该特性： * Node.js：终端敲 node 即可进入 Node REPL（输入 .exit 退出）； * Python：终端敲 python 进入，输入 exit() 或按快捷键 Ctrl + Z（Windows）/ Ctrl + D（Mac/Linux）退出。

flowchart LR
